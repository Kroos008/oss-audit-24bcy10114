## Project Description
This project is a detailed analysis of Git, including its origin, philosophy, licensing, and its role in open-source software. It also includes five shell scripts demonstrating Linux concepts and automation.

## Scripts Overview

### Script 1 — System Identity Report
Displays system details such as OS, kernel, user, uptime, and date.

### Script 2 — FOSS Package Inspector
Checks whether Git is installed and displays its version and details.

### Script 3 — Disk and Permission Auditor
Shows directory permissions, ownership, and disk usage.

### Script 4 — Log File Analyzer
Counts occurrences of a keyword in a log file and displays matching entries.

### Script 5 — Manifesto Generator
Generates a personalized open-source philosophy statement.
